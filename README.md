# Smart Disease Diagnosis System Using Machine Learning

## Project Overview

This project focuses on the application of Artificial Intelligence and Machine Learning in healthcare for disease prediction based on patient symptoms.

The project is divided into two parts:

1. **Case Study (PDF):** A theoretical study of Biomedical Devices with Artificial Intelligence, discussing the role, applications, benefits, and future scope of AI in healthcare.
2. **Practical Test (Jupyter Notebook):** An implementation of a Smart Disease Diagnosis System using Python and Machine Learning to predict possible diseases based on symptoms provided as input.

## Repository Contents

| File | Description |

## 1. Case Study – Biomedical Devices with AI

The seminar report explores how Artificial Intelligence is transforming modern healthcare.

Topics covered include:
- AI in medical imaging and diagnostics.
- Machine Learning in disease detection.
- AI-powered wearable devices and remote patient monitoring.
- Surgical robotics.
- AI-based drug discovery.
- Future scope and challenges of AI in healthcare.

The PDF serves as the **theoretical and research-based component** of this project.

## 2. Practical Test – Smart Disease Diagnosis System

The Jupyter Notebook demonstrates the practical implementation of a machine learning-based disease prediction system.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn (where applicable)
- Jupyter Notebook / Google Colab

### Machine Learning Algorithm

**Random Forest Classifier**

The model is trained using a symptom-based dataset containing multiple symptoms and their corresponding disease labels.

### Working Process

1. Import the required Python libraries.
2. Load the training and testing datasets.
3. Preprocess the symptom data.
4. Train the Random Forest classification model.
5. Evaluate the model using test data.
6. Accept symptoms as input.
7. Predict the possible disease.
8. Display the prediction and basic health guidance.

### Model Performance

**Reported Model Accuracy: 97.62%**
